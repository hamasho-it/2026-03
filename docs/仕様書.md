# アプリ仕様書：Trashbusters

## 1. アプリの名前と目的
* **アプリ名**: Trashbusters
* **目的**: 地元を綺麗にしたい住民（趣味で散歩をする人、子供を外で運動させたい人など）が、ゴミ拾いを通じてポイントを獲得し、地元の店舗の商品等と交換できるようにすることで、楽しみながら地域美化活動を行えるようにする。

## 7. 守る条件

1. **技術スタック**: HTML / CSS / JavaScript のみで構成（データベース、ログイン機能は作成しない）。
2. **ディレクトリ構成**: 画面ごとに独立したHTMLファイルを作成し、共通スタイル sheets (`./style.css`) および共通スクリプト (`./script.js`) を相対パスで読み込む。
3. **リンク指定**: すべてのファイル読み込みおよびページ遷移は相対パス（`./`から始まる形式）で記述する。
4. **表示デザイン**: 白・黒・灰色を基調としたレスポンシブなスマートフォン表示サイズ（仮デザイン）とする。
5. **UI文言の遵守**: ボタン等のテキスト表記はワイヤーフレームおよび指定文言に厳密に準拠する（括弧表記などの仮表記は削除）。

## 8. 確認したいこと（図にない・決まっていないこと）

1. **ホームと撮影の間の画面について**: 遷移図上で「ホーム」と「撮影」の間に存在する灰色の空欄枠について、カメラ起動許可画面（`photo_prep.html`）として仕様化していますが、正しいか確認が必要です。
2. **「色々」画面の詳細**: 設定画面およびゲーム画面から遷移する「色々」と表記された画面（`settings_detail.html`, `game_detail.html`）の具体的な表示構成・UI要素。
3. **ランキング画面のタブ・ボタン対応**: ワイヤーフレーム下部のボタン（「全期間ポイント数のランキング」「一日の拾い物ランキング」「デイリー」「現在のポイント数ランキング」）と遷移図内の「全期間の拾い物ランキング」「ゲームのランキング」の対応関係および遷移条件。
4. **「ホームへ戻る」と下部ナビゲーションの重複**: 各画面に配置されている「ホームへ戻る」ボタンと、下部ナビゲーションバーからの遷移（ホームへの直接復帰機能）の優先度と挙動。
